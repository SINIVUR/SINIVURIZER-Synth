SINIVURIZER Synth — 설치 방법 (PWA)

1) 이 폴더 전체를 한 곳에 압축 해제합니다.
2) 폴더 안에서 터미널(명령 프롬프트)을 열고 아래 명령을 실행합니다.
     python -m http.server 8080
   (Python이 없다면 VS Code의 Live Server 확장 등 아무 로컬 서버나 괜찮습니다.)
3) Chrome 또는 Edge에서 http://localhost:8080 에 접속합니다.
4) 주소창 오른쪽의 설치 아이콘(⊕) 또는 앱 상단의 [📥 앱 설치] 버튼을 누르면
   바탕화면/시작 메뉴에 앱으로 설치됩니다. 설치 후에는 인터넷 없이도 실행됩니다.

※ index.html을 더블클릭해서 열어도 모든 기능을 쓸 수 있지만, "앱 설치"는 위처럼 서버로 열었을 때만 나타납니다.
※ GitHub Pages / Netlify에 폴더째 올리면 어디서든 설치할 수 있습니다.
